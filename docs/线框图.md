# 凯俊后台 UI 线框（文本）

> 来源：PRD v0.3 信息架构  
> 用途：阶段门 2 补件；Stitch 视觉稿对照底稿  
> 约定：`[…]` 可点击；`{}` 数据字段；【状态】为三字段标签

## 全局壳（桌面端 1280+）

```
┌──────────────────────────────────────────────────────────────┐
│ 侧边导航（固定 ~200px）          顶栏（可选）：当前页标题      │
│ ├ [总览]                      ┌───────────────────────────── │
│ ├ [项目]                      │  内容区                       │
│ ├ [任务]                      │                              │
│ ├ [工时]                      │                              │
│ ├ [调研]                      │                              │
│ ├ [话术]                      │                              │
│ └ [设置/退出登录]             │                              │
└──────────────────────────────────────────────────────────────┘
```

导航高亮当前页；移动端可折叠为顶栏（MVP 以桌面为主）。

## 2. 总览 Dashboard（P0/P1 关键页）

**目标**：一眼看到「今天要跟谁」「本月钱和工时」。

```
┌───────────────┬──────────────────────────────────────────────┐
│ 侧边导航       │ 总览                                        │
│               │                                              │
│               │ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐        │
│               │ │待跟进 │ │在跟项目│ │本月成交│ │本月工时 │        │
│               │ │ {n}  │ │ {n}  │ │ ¥{x} │ │ {h}h │        │
│               │ └──────┘ └──────┘ └──────┘ └──────┘        │
│               │                                              │
│               │ 【今日/逾期待跟进】            [查看全部项目] │
│               │ ┌──────────────────────────────────────┐    │
│               │ │ {下次跟进日} {项目名} 【阶段】【成交】【状态】│
│               │ │ 客户：{customer}        [去跟进]      │    │
│               │ │ … 最多 5 条，按日期升序                │    │
│               │ └──────────────────────────────────────┘    │
│               │                                              │
│               │ 【阶段分布】          【最近跟进 5 条】       │
│               │ 意向 ████ 2              {date} {项目} 摘要  │
│               │ 需求 ██ 1                …                  │
│               │ 报价 █████ 3                                  │
│               │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

**卡片含义**
- 待跟进：`following|waiting` 且 `next_follow_up_at ≤ 今天`
- 本月成交：`is_deal=yes` 且成交月=当月的金额合计
- 本月工时：当月 `hours` 合计

## 3. 项目列表（P0 关键页）

**目标**：列表内直接看到三字段 + 下次跟进日，支持筛选。

```
┌───────────────┬──────────────────────────────────────────────┐
│ 侧边导航       │ 项目                            [+ 新建项目] │
│               │ ┌ 筛选条 ─────────────────────────────────┐  │
│               │ │ 状态▾ 阶段▾ 成交▾ [今日待跟进☑] [搜索]   │  │
│               │ └────────────────────────────────────────┘  │
│               │                                              │
│               │ ┌表─────────────────────────────────────┐   │
│               │ │ 项目名 │客户│阶段│成交│状态│下次跟进│预计金额│ │
│               │ ├────────┼────┼───┼───┼───┼──────┼─────┤   │
│               │ │ {name} │{c} │报价│未 │待回复│06-12│¥8万 │   │
│               │ │ …      │    │   │   │    │      │     │   │

│               │  行点击 → 项目详情                            │
```

**列要求（不可省略）**：项目名、阶段【tag】、是否成交【tag】、当前状态【tag】、下次跟进日（逾期红/今日橙）、预计金额。  
**筛选**：状态 / 阶段 / 是否成交 / 仅今日待跟进 / 关键词。

## 4. 项目详情 / 跟进（P0 关键页）

**目标**：顶部三字段常驻；右侧/下方完成「记跟进 → 约下次 → 定性/重启」。

```
┌───────────────┬──────────────────────────────────────────────┐
│ 侧边导航       │ ← 返回列表   {项目名称}          [编辑]     │
│               │ ┌──────────────────────────────────────┐    │
│               │ │ 阶段【方案/报价】 成交【未成交】        │    │
│               │ │ 状态【待客户回复】 下次跟进 06-12（橙）  │    │
│               │ │ 预计 ¥80,000   成交 ¥—                 │    │
│               │ │ 客户：{name} {contact} {tags}          │    │
│               │ └──────────────────────────────────────┘    │
│               │                                              │
│               │ [记跟进] [成交] [无法成交] [暂停] [延后] [重新启动] │
│               │                                              │
│               │ ┌ 左：跟进时间线 ──────┬ 右：记跟进（表单） ┐ │
│               │ │ 06-10 微信 已发报价  │ 跟进时间 [今天]     │ │
│               │ │   客户未回           │ 方式 [微信▾]       │ │
│               │ │   下次：06-12        │ 结果正文 [________] │ │
│               │ │                      │ 下次跟进日 [  ]    │ │
│               │ │ 06-08 电话 约周四沟通 │ [保存跟进]         │ │
│               │ │   下次：06-10        │                    │ │
│               │ │ …（新→旧）           │                    │ │
│               │ └──────────────────────┴────────────────────┘ │
│               │                                              │
│               │ 关联：[任务 n] [工时 n] [调研 n]   ← 标签页可选 │
└───────────────┴──────────────────────────────────────────────┘
```

**动作按钮规则**
- 跟进中/待回复 → 显示 成交 / 无法成交 / 暂停 / 延后
- 无法成交/暂停/延后 → **[重新启动]** 置顶高亮
- 已成交 → 弱化，仅显示已成交归档
- 「成交」弹窗必填成交金额；「无法成交」弹窗可选原因备注

**状态色（线框约定，进 UI 规范）**
- 跟进中=蓝 · 待客户回复=橙 · 暂停/延后=灰 · 无法成交=红 · 已成交=绿

## 7. 调研（P0）/ 8. 话术（P0）— 简表

调研：`[+ 新建]` 标题/来源/结论/标签/关联项目；列表 + 关键词搜索。  
话术：场景筛选 + 列表 + **[复制]**；详情可整段复制。

## 页面优先级（Stitch）

| 优先级 | 页面 | Stitch |
|---|---|---|
| P0 视觉 | 总览、项目列表、项目详情/跟进 | 是（+1~2 备选） |
| P0 结构 | 登录、任务、工时、调研、话术 | 线框即可，视觉可后补 |
| P1 | 总览完整仪表盘、看板 | 不进本期 Stitch |
