# 文件地图（页面 / 接口 → 文件）

> 给你自己写 Cursor 小提示词用：先在下表找到路径，再写「只改 xxx」。  
> 路径相对仓库根目录 `D:\XMMM\凯俊后台`。

## 一、浏览器地址 → 前端页面文件

| 你在浏览器看到 | 路由 | 主文件 |
|---|---|---|
| 登录页 | `/login` | `frontend/src/pages/LoginPage.jsx` |
| 总览（未成交跟进 / 工作项双列表） | `/` | `frontend/src/pages/HomePage.jsx` |
| 项目列表（筛选、表格） | `/projects` | `frontend/src/pages/ProjectListPage.jsx` |
| 新建项目 | `/projects/new` | `frontend/src/pages/ProjectFormPage.jsx` + `frontend/src/components/ProjectForm.jsx` |
| 编辑项目 | `/projects/:id/edit` | 同上两个 |
| 项目详情（三字段、跟进、动作） | `/projects/:id` | `frontend/src/pages/ProjectDetailPage.jsx` |
| 工作项列表 | `/work-items` | `frontend/src/pages/WorkItemListPage.jsx` |

## 六、写提示词时怎么用这张表

1. 在浏览器看到问题 → 对应 **§一** 找到页面文件  
2. 若是接口报错 → 对应 **§三** 找控制器  
3. 提示词里写清，例如：

```text
只改 frontend/src/pages/ProjectListPage.jsx：
把「开始日」列宽改成 120，右对齐。
别动后端和别的页面。
```

或接口：

```text
只改 backend/app/Http/Controllers/SummaryController.php：
open_work_items 里 overdue 时额外返回 due_tone=overdue|today。
并在 frontend/src/pages/HomePage.jsx 用这个字段显示颜色。
```

**不确定时**：把浏览器地址 + 你看到的现象发给 Cursor，让它先读本文件再改，例如：

```text
先读 docs/文件地图.md。
总览页（/）卡片间距太小，改到 16px。
只动对应页面文件和必要 CSS。
```
