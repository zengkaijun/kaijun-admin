# 凯俊后台 PRD

> 状态：v0.1 草稿 · 待用户确认（确认前不进入方案阶段）

## 背景与目标

**背景**：个人与身边协作者的工作数据（任务、资料、联系人）目前散落在记忆、聊天和零散记录里，没有固定表结构，查找和跟进成本高，希望用一个自用后台替代手工管理。

**目标（本期成功标准）**：日常主流程可在后台完成，**替代现有手工/Excel 式管理**；一个可演示场景——登录后能：① 看到今日待办与任务看板；② 新增/搜索联系人并记录跟进；③ 按标签上传/检索资料，不再依赖翻聊天记录或本地文件夹。

## 目标用户

| 用户 | 说明 |
|---|---|
| 主用户 | 本人（管理员） |
| 次要用户 | 身边少量协作者（只读或有限编辑，数量按 ≤5 人假设） |

典型场景：每天打开后台看待办、改任务状态；见面前查联系人与上次沟通；找某份资料时按标签/关键词搜。

## 验收标准

### 登录

- **Given** 未登录访问后台  
- **When** 输入正确账号密码登录  
- **Then** 进入首页，刷新后仍保持登录；错误密码有明确提示

### 任务管理

- **Given** 已登录  
- **When** 新建任务「整理周报」，截止今天，状态「待办」  
- **Then** 列表可见该任务；标记完成后从待办筛选中消失；首页待办计数 −1

### 联系人与跟进

- **Given** 已登录  
- **When** 新增联系人「张三」并添加一条跟进「已加微信，下周聊合作」  
- **Then** 按姓名能搜到张三；打开详情能看到按时间排序的跟进记录

### 资料检索

- **Given** 已存在标签为「合同」的资料 2 条  
- **When** 用标签「合同」或关键词搜索  
- **Then** 两条均出现在结果中

### 替代手工（里程碑验收）

- **Given** 后台已有任务、联系人、资料各若干  
- **When** 模拟一天工作：查待办 → 记跟进 → 找资料  
- **Then** 无需打开原 Excel/翻聊天即可完成上述三步

## 非目标（本期明确不做）

- 「有趣的小功能/玩具」——记入 backlog，本期不做  
- 复杂权限体系、多租户、开放注册  
- 与外部 IM/日历/网盘的深度集成  
- 报表 BI、移动端原生 App（浏览器可用即可）  
- 高并发与公网上线运维（优先本机或内网使用）

## 假设（可被你改掉）

1. 部署形态：先 **本机或局域网** 自用，不强制公网。  
2. 数据量：单用户日常量级，关系型数据库即可。  
3. 身边协作者 ≤5 人，权限可后补（P2）。  
4. 资料以「元数据 + 标签」为主，附件存储可简化。  
5. 表结构未定时，字段允许在开发初期微调，但以本 PRD 字段为基线。
