# 凯俊后台 PRD

> 状态：v0.4 **已确认**（用户已拍板；变更须走 PRD 变更流程）  
> 组织主线：**以项目为中心**；单人使用；客户依附项目；跟进可循环直至定性或重启；成交后可建关联升级项目

## 背景与目标

**背景**：项目靠文件夹（未成交 / 已成交 / 升级）+ 备忘录手工跟，易漏跟进、难一眼看清该跟什么、活干完没。

**目标（成功标准）**：登录后能演示——① 建项目（名 / 开始日 / 客户必填）→ ② 记跟进并约下次 → ③ 首页仪表盘看到**待跟进**和**未完成工作项** → ④ 成交挂到关联升级项目 / 无法成交定性 / 客户回头重启。

## 目标用户

| 用户 | 说明 |
|---|---|
| 主用户 | 本人 IT 产品经理（唯一管理员） |

## 信息架构

```text
总览（仪表盘）
├── 项目（主线）
│   ├── 档案：名称、开始日、客户、阶段、是否成交、状态、金额…
│   ├── 跟进时间线 + 下次跟进日
│   ├── 工作项（里程碑 + 待办，可挂本项目）
│   └── 关联升级项目（成交后迭代）
├── 工作项（全局；可独立、可挂项目）
├── 账号与设置（登录/退出）
```

## 核心概念

### 项目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 项目名称 | ✅ | |
| 项目开始日期 | ✅ | 立项日 |
| 客户名称 | ✅ | |
| 阶段 | 后补可 | 意向 → 需求沟通 → 方案/报价 → 完成（提案，可改） |
| 是否成交 | 后补 | 未成交 / 已成交 |
| 当前状态 | 后补 | 跟进中 · 待客户回复 · 暂停 · 延后 · 无法成交 · 已成交归档 · 已重新启动（提案） |
| 预计/成交金额 | 可空 | |
| 关联原项目 | 可空 | 升级迭代项目指回源项目 |

### 跟进（每次必记 / 可选）

- **必记**：跟进时间（默认今天）、方式（沟通/电话/微信/报价/其他）、内容正文、**下次跟进日（可空）**
- **可选**：是否推进阶段、是否改当前状态

### 工作项（拆活）

| 字段 | 说明 |
|---|---|
| 标题 | 必填 |
| 状态 | 未做 / 进行中 / 已完成 |
| 截止日 | 可空 |
| 关联项目 | 可空（独立杂事） |
| 类型 | **里程碑**（阶段节点）或 **待办**（默认待办） |

里程碑示例：需求 → 开发 → 测试 → 交付（挂在项目下）。

### 升级迭代

成交后：**新建关联项目**（填原项目），在新项目下继续跟进 / 工作；原项目保持已成交归档。

## 首页仪表盘（P0）

至少两块：

1. **待跟进**：状态∈跟进中 / 待客户回复（等），且下次跟进日 ≤ 今天；按日期排序  
2. **未完成工作项**：状态≠已完成；（有截止日则标出是否过期）

可选后续：阶段分布、本月成交金额（P1）。

## 功能清单（按模块）

### 账号
- 登录 / 退出，会话保持

### 项目
- 项目列表：名称、客户、开始日、阶段、是否成交、当前状态、下次跟进日  
- 新建 / 编辑项目；名称、开始日、客户为必填  
- 阶段流转；状态流转（跟进中、待客户回复、暂停、延后、无法成交、已成交、已重新启动）  
- 项目详情：阶段 / 是否成交 / 状态一眼可见 + 跟进时间线  

### 跟进
- 记一条跟进：时间、方式、内容、下次跟进日（可空）  
- 跟进历史只增不删  
- 一键动作：成交、无法成交、暂停、延后、重新启动  

### 工作项（拆活）
- 新增 / 编辑 / 完成 / 删除  
- 可挂项目，也可独立存在  
- 两种类型：里程碑（阶段节点）、待办  
- 字段：标题、状态（未做 / 进行中 / 已完成）、截止日（可空）  
- 按状态、按项目筛选  

### 关联升级项目
- 成交后可新建项目并关联原项目（用于迭代升级）  
- 列表 / 详情能看出它挂在哪个源项目下  

### 总览（首页仪表盘）
- **待跟进**：该跟的项目按下次跟进日排  
- **未完成工作项**：还没做完的活（含是否过期）  
- （P1 可选）阶段分布、本月成交金额等汇总卡  

优先级说明：

- **P0**：上面除「P1 可选汇总卡」外的全部  
- **P1**：总览里的金额 / 分布增强卡  
- **本期不做**：多账号、系统推送、工时 / 调研 / 话术（用户未点名要加）

## 验收标准（演示路径）

1. **GIVEN** 新建项目（名 + 开始日 + 客户）**WHEN** 保存 **THEN** 列表可见  
2. **GIVEN** 项目记一条跟进、下次 = 明天 **WHEN** 明天打开首页 **THEN** 出现在待跟进  
3. **GIVEN** 挂未完成工作项 **WHEN** 打开首页 **THEN** 未完成工作项区可见  
4. **GIVEN** 点成交 **WHEN** 确认 **THEN** 是否成交 = 已成交；可建关联升级项目  
5. **GIVEN** 点无法成交 **WHEN** 确认 **THEN** 退出待跟进；客户回头重启后历史仍在、回到待跟进逻辑  
6. 未登录访问业务 API → 拒绝  

## 非目标（本期不做）

- 多用户权限、消息推送 / 邮件、移动端优先适配  
- 工时、调研库、话术库、CSV 导出（除非用户点名要加回）  
- 自动日历提醒系统（MVP = 首页列表，不做系统通知）
