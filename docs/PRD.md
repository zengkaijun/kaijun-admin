# 凯俊后台 PRD

> 状态：v0.3 **已确认**（用户已拍板；变更须走 PRD 变更流程）  
> 组织主线：**以项目为中心**；客户依附项目；跟进可循环直至定性或重启

## 背景与目标

**背景**：本人为 IT 产品经理，工作围绕**项目**展开：需求沟通、方案/报价、反复跟进直至成交或无法成交、项目暂停/延后/升级，以及调研、工时、话术沉淀。缺少统一后台时，难一眼看清「项目现在什么阶段、是否成交、当前状态」，跟进节奏也易断。

**目标（本期成功标准）**：以项目为主线完成主流程，**替代手工/Excel**。可演示场景——登录后：① 列表/总览看清每个项目的**阶段、是否成交、当前状态**；② 打开项目可连续跟进（本次未果 → 设定下次跟进日 → 再记再约）；③ 可将项目定性为「无法成交」，或客户回头后**重新启动**跟进；④ 关联记录工时、调研、话术与金额。

## 信息架构（主线）

```text
总览（首页）
├── 项目（主线）
│   ├── 项目档案（名称、阶段、成交与否、当前状态）
│   ├── 客户信息（依附本项目）

├── 调研库（可挂项目）
├── 话术库（按场景）
└── 账号与设置
```

## 核心模型：项目 · 状态 · 跟进

### 1. 项目与状态（用户需一眼可见）

| 概念 | 含义 | 说明 |
|---|---|---|
| **阶段** | 商务/过程阶段 | 意向 → 需求沟通 → 方案/报价 → （结果向） |
| **是否成交** | 结果字段 | 未成交 / 已成交（金额归档） |
| **当前状态** | 运行状态 | 跟进中 · 待客户回复 · 暂停 · 延后 · **无法成交** · 已成交归档 · **已重新启动** |

推荐默认流转（可改）：

```text
创建项目 → 跟进中/待客户回复 ⇄（反复跟进）
    ├─→ 成交（是否成交=已成交，记成交金额）
    ├─→ 暂停 / 延后（可再启动跟进）
    ├─→ 无法成交（定性，停止默认跟进）
    └─→ 客户回头 → 重新启动（状态回到跟进循环，历史保留）
```

列表与总览必须展示至少：**项目名、阶段、是否成交、当前状态、下次跟进日（若有）**。

### 2. 跟进循环（P0 核心交互）

**场景**：今天报价/沟通需求 → 客户没反应 → 明天再跟 → 后天或隔一周再跟……直到定性；若客户又来找，重新启动。

**每次跟进需记录**：
- 跟进时间（默认今天）
- 跟进方式（沟通/电话/微信/报价/其他）
- 结果与信息正文（客户说了什么、没反应等）
- **下次跟进日期**（可空 = 暂不约；间隔你定：1 天、2 天、1 周……不固定）
- 可选：本次是否推进了阶段

**规则**：
1. 有「下次跟进日」且未过期 → 项目显示为「待客户回复 / 跟进中」，总览「待跟进」列表按日期排序。  
2. 到期未处理 → 仍出现在待跟进，可再记一条跟进并再约下次。  
3. 连续跟进直到你主动定性：**无法成交** 或 **成交** 或 **暂停/延后**。  
4. **无法成交**后默认不再进待跟进；客户回头 → **重新启动** → 恢复跟进循环，**历史跟进全部保留**。  
5. 暂停/延后后同样可再启动跟进（与「重新启动」共用恢复能力）。

## 验收标准

### 项目三字段一眼可见

- **Given** 存在项目「某系统定制」，阶段「方案/报价」，未成交，状态「待客户回复」  
- **When** 打开项目列表或详情  
- **Then** 能直接看到阶段、是否成交、当前状态（无需点进多层）

### 跟进循环：隔日再跟

- **Given** 项目在跟进中，今天已记跟进「已发报价，客户未回」，下次跟进日=明天  
- **When** 到明天（或你打开待跟进）  
- **Then** 该项目出现在待跟进；再记一条「再次询问」并设下次=3 天后 → 时间线两条记录，3 天后再次待跟进

### 间隔不定（隔一天/两天/一周）

- **Given** 同一项目  
- **When** 分别将下次跟进日设为 +1 天、+2 天、+7 天并保存  
- **Then** 待跟进列表按各自日期出现，互不覆盖历史记录

### 定性无法成交

- **Given** 多次跟进仍无进展  
- **When** 将项目标为「无法成交」  
- **Then** 是否成交仍为未成交；当前状态=无法成交；默认退出待跟进；历史跟进仍可查

### 重新启动

- **Given** 项目已「无法成交」  
- **When** 客户回头，点击「重新启动」并记一条新跟进  
- **Then** 状态回到跟进循环（如跟进中/待客户回复）；旧记录与新记录连续展示；可再约下次跟进

### 成交与金额归档

- **Given** 项目「方案/报价」，预计 80000  
- **When** 标记已成交，成交金额 75000  
- **Then** 是否成交=已成交；列表与汇总可见；状态含已成交/归档

### 工时 / 调研 / 话术（简）

- **Given** 已登录  
- **When** 按条记 2.5h 工时挂本项目；新增调研与话术  
- **Then** 项目下可查工时；调研/话术可按标签或关键词搜到

### 里程碑：替代手工

- **Given** 多项目含跟进史  
- **When** 查看待跟进 → 补跟进 → 定性或重启 → 看成交汇总  
- **Then** 主流程不依赖 Excel/聊天记录

## 非目标（本期不做）

- 有趣小功能（backlog）  
- 自动发消息催办、智能预测成交概率  
- 完整报价单文档与版本对比（金额+阶段足够）  
- 多级审批、复杂权限、多租户  
- IM/日历深度集成；公网高并发运维  

## 假设（可被你改掉）

1. 本机/局域网部署。  
2. 「重新启动」适用于：无法成交、暂停、延后 后的恢复，历史全保留。  
3. 阶段名与状态名可在方案阶段微调文案，模型不变。  
4. 工时手动补录；金额为简单数值汇总。  
5. 字段以本 PRD 为基线，开发初期可微调。
