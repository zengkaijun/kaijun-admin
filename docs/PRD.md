# 凯俊后台 PRD

> 状态：v0.2 草稿 · 待用户确认（确认前不进入方案阶段）  
> 组织主线：**以客户/商机为中心**，工时、调研、话术挂靠客户或独立沉淀

## 背景与目标

**背景**：本人为 IT 产品经理，日常工作分散在：客户沟通与需求转化、方案/报价与成交归档、项目调研、每日工时、话术沉淀。缺少统一后台，跟进状态、金额、工时与经验库难一处查阅。

**目标（本期成功标准）**：主工作流可在后台完成，**替代手工/Excel 式管理**。可演示场景——登录后：① 看到在跟客户阶段与金额汇总、今日待办；② 给某客户记一条工时、一条跟进、一条调研笔记；③ 从阶段推进到「成交/暂停/延后」并归档金额；④ 按场景检索话术用于下次沟通。

## 目标用户

| 用户 | 说明 |
|---|---|
| 主用户 | 本人 IT 产品经理（管理员） |
| 次要用户 | 身边协作同事（≤5 人，P2 再开） |

## 信息架构（主线）

```text
总览（首页）
├── 客户/商机（主线）
│   ├── 客户档案 + 跟进记录
│   ├── 商机阶段 + 预计/成交金额
│   └── 关联：任务、工时、调研
├── 工时（每日按条）
├── 调研库（可挂客户，也可独立）
├── 话术库（按场景分类）
└── 账号与设置
```

## 验收标准

### 登录

- **Given** 未登录  
- **When** 正确账号密码登录  
- **Then** 进入总览；刷新保持登录；错误密码有明确提示

### 客户阶段与金额（对应：是否成交、金额归档）

- **Given** 已有客户「某科技公司」，阶段「方案/报价」，预计金额 80000  
- **When** 更新为「成交」，填写成交金额 75000  
- **Then** 该客户进入成交列表；首页本月成交金额汇总包含 75000

### 暂停 / 延后归档

- **Given** 某在跟商机  
- **When** 阶段改为「暂停」或「延后」并备注原因  
- **Then** 不再计入「在跟」预计金额；仍可搜索到并恢复阶段

### 每日工时（对应：按小时记录）

- **Given** 已登录  
- **When** 新增工时：今天、2.5h、关联客户 X、简述「需求评审」  
- **Then** 今日合计增加 2.5h；客户 X 下可查到该条；可按周合计

### 跟进与任务

- **Given** 客户 A  
- **When** 新增跟进「已发报价单」，并新建任务「周三催决策」  
- **Then** 客户时间线可见跟进；任务列表可筛选关联客户 A

### 调研沉淀（对应：第三方/平台规则、可行性）

- **Given** 已登录  
- **When** 新增调研：标题「XX 平台入驻规则」、结论摘要、标签「规则」  
- **Then** 可按标签或关键词搜到，可选择关联到客户 B

### 话术库（对应：沟通话术储备）

- **Given** 已有话术「报价后无回复」  
- **When** 按场景「报价异议」或关键词搜索  
- **Then** 命中条目并可一键复制正文

### 里程碑：替代手工

- **Given** 后台已有若干客户、工时、调研、话术  
- **When** 模拟一天：查在跟商机 → 记工时 → 记跟进 → 搜话术/调研  
- **Then** 无需 Excel / 翻聊天记录即可完成

## 非目标（本期不做）

- 有趣的小功能 / 玩具类入口（backlog）  
- 完整 CRM：公海池、销售漏斗 BI、自动催办机器人  
- 完整报价单文档生成与版本对比（金额与阶段足够；报价文件可作资料附件 P1）  
- 考勤打卡、审批流、复杂权限与多租户  
- 与企微/钉钉/日历深度集成  
- 公网上线与高并发运维（优先本机/内网）

## 假设（可被你改掉）

1. 部署：本机或局域网自用。  
2. 金额：简单数值 + 日期汇总即可，不做过币种与税率。  
3. 工时：手动补录为主，不做打卡。  
4. 升级迭代：作为客户下的跟进/任务或新商机记录，不单独做产品版本管理。  
5. 表结构以本 PRD 为基线，开发初期字段可微调。

## 与 v0.1 的差异

| v0.1 | v0.2 |
|---|---|
| 泛化：任务/联系人/资料 | 以**客户/商机**为主线，贴合 IT 产品工作流 |
| 无工时、话术、调研独立能力 | 增加 **工时、调研库、话术库** P0 |
| 联系人中心 | **客户阶段 + 预计/成交金额 + 简单汇总** |
