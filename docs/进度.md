### T1 Docker + Laravel + React 骨架与登录

**任务**：Docker Compose 起 MySQL/PHP/前端，Laravel API 登录，React 登录壳可跑。  
**前置**：技术方案 v2 已确认。  
**做法**（给 Cursor 的提示词）：

```text
【背景】凯俊后台：IT 产品经理个人工作台（以项目为主线）。技术栈已定：Docker Compose + Laravel 12/PHP 8.4 + MySQL（compose 镜像 mysql:9，不行则 mysql:lts）+ Vite/React/AntD。本任务只搭可运行骨架与登录，不做项目/跟进业务。
【任务】在仓库根目录：
1. 编写 docker-compose.yml：服务 db（mysql:9，卷 mysql-data，127.0.0.1:3306）、app（php:8.4-cli，装 pdo_mysql/mbstring/zip，挂载 backend/，127.0.0.1:8000 跑 artisan serve）、web（node:22，挂载 frontend/，127.0.0.1:5173，vite 代理 /api→app:8000）。
2. 在 backend/ 初始化 Laravel（可 composer create-project 于容器内），routes/api.php：POST /api/auth/login、POST /api/auth/logout、GET /api/auth/me；session cookie 认证；users 表迁移；AdminUserSeeder（管理员账号从 env 读取，密码哈希存储）。
3. frontend/ 初始化 Vite+React+AntD：登录页、登录后占位首页；调用 /api/auth/*。
4. 根目录 .env.example、.gitignore（.env、vendor、node_modules、storage logs）、README.md（克隆→compose up→migrate→seed→访问步骤，适配其他电脑）。
【约束】遵守 AGENTS.md 与 .cursor/rules；禁止任何密钥/真实口令入库；只加骨架必需依赖；不实现业务模块；端口仅绑 127.0.0.1。
【验收】
1. docker compose up -d 后按 README 可完成迁移与种子；
2. 浏览器登录成功见占位页，错误密码有提示；
3. 登出后访问 /api/auth/me 为 401；
4. git status 无 .env/vendor/node_modules；
5. 换目录按 README 复述步骤可复现（文档无缺失命令）。
【完成后】列出改动文件清单、docker compose 服务列表，并告诉我如何运行验证。
```

**验收**：提示词【验收】五条；回传终端与浏览器结果/截图。

**前置**：T2。

```text
【背景】凯俊后台核心：PRD 跟进循环。实现见 docs/PRD.md 验收与 docs/技术方案.md 状态机。

2. 无法成交退出待跟进；重新启动后历史完整并回到跟进；
3. 成交写入金额与 is_deal；
4. 非法流转 400/422 且前端提示。
【完成后】列出改动文件与验证方式。
```
