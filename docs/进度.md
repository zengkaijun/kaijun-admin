**做法**：

```text
【背景】凯俊后台：IT 产品经理个人工作台（单人）。栈：Docker Compose + Laravel 12/PHP 8.4 + Octane(swoole) + MySQL 8.4 + Vite/React/AntD。无 Redis。PRD 见 docs/PRD.md v0.4；方案见 docs/技术方案.md。

   - db: mysql:8.4，卷 mysql-data，127.0.0.1:3306，健康检查
   - app: 基于 backend/Dockerfile（php:8.4-cli + pdo_mysql/mbstring/zip/swoole）；挂载 backend/；command: php artisan octane:start --server=swoole --host=0.0.0.0 --port=8000；127.0.0.1:8000；SESSION_DRIVER=database

4. 根目录 .env.example、.gitignore（.env、vendor、node_modules、storage）、README.md：clone → compose up --build → key:generate → migrate → seed → 打开 5173；说明 app 日志可见 Swoole/Octane

2. docker compose logs app 可见 Octane/Swoole 启动
3. 浏览器登录成功；错误密码有提示；登出后 /api/auth/me 为 401
4. git status 无 .env/vendor/node_modules
5. Swoole 构建失败：贴报错，临时 artisan serve 跑通登录并在汇报中说明
```

```text
2. 无法成交退出待跟进；重启后历史完整并回到待跟进逻辑
3. 成交写入 is_deal/状态；金额可填
```
