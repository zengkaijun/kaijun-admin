### T1 Docker + Laravel(Octane/Swoole) + React 骨架与登录

**任务**：Docker 起 MySQL/带 Swoole 的 PHP/前端，Octane 提供 API，React 登录壳可跑。  
**前置**：技术方案 v2.1 已确认。  
**做法**（给 Cursor 的提示词）：

```text
【背景】凯俊后台：IT 产品经理个人工作台。技术栈：Docker Compose + Laravel 12/PHP 8.4 + Swoole（经 laravel/octane，服务器 swoole）+ MySQL9（备选 mysql:lts）+ Vite/React/AntD。本任务只搭骨架与登录。
【任务】仓库根目录：
1. docker-compose.yml：
   - db: mysql:9，卷 mysql-data，127.0.0.1:3306
   - app: 自定义 Dockerfile 基于 php:8.4-cli，安装 pdo_mysql、mbstring、zip、swoole（pecl/docker-php-ext-enable）；挂载 backend/；command 跑 php artisan octane:start --server=swoole --host=0.0.0.0 --port=8000；127.0.0.1:8000
   - web: node:22，挂载 frontend/，127.0.0.1:5173，vite 代理 /api→app:8000
2. backend/ 初始化 Laravel；composer require laravel/octane；配置 octane server=swoole；routes/api.php：POST /api/auth/login、POST /api/auth/logout、GET /api/auth/me；session 认证（若 Octane 下 session 异常，改 SESSION_DRIVER=database 并写进 README）；users 迁移；AdminUserSeeder（账号密码来自 env，只存哈希）。
3. frontend/：Vite+React+AntD 登录页与占位首页，调 /api/auth/*。
4. 根目录 .env.example、.gitignore（.env、vendor、node_modules、storage）、README.md：clone → compose up --build → key:generate → migrate → seed → 打开 5173；并说明 app 日志里能看到 Swoole/Octane 启动。
【约束】遵守 AGENTS.md；禁止密钥入库；只加骨架依赖（composer：octane 等；扩展：swoole 等，各一句理由）；端口仅 127.0.0.1；不写业务模块。
【验收】
1. docker compose up -d --build 后按 README 完成迁移种子；
2. docker compose logs app 可见 Octane/Swoole 启动（或文档写明的等价日志）；
3. 浏览器登录成功；错误密码有提示；登出后 /api/auth/me 为 401；
4. git status 无 .env/vendor/node_modules；
5. 若 Swoole 扩展构建失败：给出报错原文，并按方案降级 artisan serve 跑通登录（仍须在汇报中说明）。
【完成后】列出改动文件、compose 服务列表、启动命令，并告诉我如何运行验证。
```

**验收**：提示词【验收】五条；回传终端与浏览器结果/截图。

1. 跟进+明日→待跟进；再跟+3 天→时间线两条日期正确；
2. 无法成交退出待跟进；重新启动后历史完整并回到跟进；
3. 成交写入金额与 is_deal；
4. 非法流转 400/422 且前端提示。
