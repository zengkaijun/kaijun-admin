# 凯俊后台 UI 规范（草稿）

> 阶段门 2 补件 · 依据 PRD v0.3 信息架构 + Stitch「凯俊后台」项目设计系统  
> 状态：草稿，随实现可修订；确认后前端按此落地

## 1. 风格定位

- **类型**：B 端效率型后台（非营销站）
- **气质**：克制、信息密度可控、状态一眼可辨
- **Stitch 项目**：`凯俊后台`（project id `16714826260744116301`）
- **设计系统**：`Kaijun Admin` · Light · Inter + PingFang SC / Microsoft YaHei

## 2. 色板（主色板以 Stitch 为准）

### 中性 / 结构

| Token | 值 | 用途 |
|---|---|---|
| background | `#F7F9FB` | 页面底 |
| surface / card | `#FFFFFF` | 卡片、表格 |
| border | `#C3C6D7` / `#E2E8F0` | 描边、分割线 |
| text primary | `#191C1E` | 正文标题 |
| text secondary | `#434655` | 次要文字 |
| muted | `#737686` | 占位、次要 |

### 品牌与语义

| 语义 | 前景 | 背景/底 | 用途 |
|---|---|---|---|
| Primary | `#2563EB` / `#004AC6` | `#EFF6FF` | 主按钮、链接、激活导航 |
| Success 已成交 | `#15803D` | `#F0FDF4` | 成交、正向指标 |
| Warning 待回复 | `#B45309` | `#FFFBEB` | 待客户回复、临期 |
| Danger 无法成交/逾期 | `#B91C1C` | `#FEF2F2` | 无法成交、逾期跟进日 |
| Neutral 暂停/延后/归档 | `#475569` | `#F1F5F9` | 暂停、延后、未成交灰标 |

**三字段状态色约定（与线框一致）**

| 状态 | 色 |
|---|---|
| 跟进中 | 蓝 |
| 待客户回复 | 橙/黄 |
| 暂停 / 延后 | 灰 |
| 无法成交 | 红 |
| 已成交 | 绿 |
| 已重新启动 | 蓝（恢复为跟进循环） |

**阶段标签**：意向 / 需求沟通 / 方案报价 / 完成——用中性底 + 文字区分，不与状态色抢语义。

## 4. 布局

```
┌──────── 240px ────┬────────────────  fluid ────────────────────┐
│ 固定侧栏 SideNav   │ 顶栏 56px（可选面包屑/搜索/主操作）          │
│                   │ 内容区 padding 24px，max-w ~1280–1600px     │
│ 总览/项目/任务/    │ 12 栅格，gutter 16px                       │
│ 工时/调研/话术/设置 │                                          │
└───────────────────┴───────────────────────────────────────────┘
```

- 断点：≥1440 宽内容可双栏；1024–1439 单列表格；&lt;1024 侧栏可收起（MVP 桌面优先）
- 表格行高 ~44px；控件高 32–36px
- 圆角：控件 4–6px，卡片 8px；阴影极浅

## 5. 组件约定

| 组件 | 约定 |
|---|---|
| 侧栏 | 固定；激活项浅蓝底 + 主色字 |
| 统计卡 | 白底描边；标题 + 大数字 + 底部分隔行 |
| 状态 Chip | 高 ~20px，圆角，可带 6px 圆点 |
| 表格 | 表头浅灰；悬停整行浅底；金额右对齐 |
| 主按钮 | 主色填充白字；次按钮白底描边；危险红底 |
| 表单 | 标签上置；错误红边 + 红字提示 |
| 待跟进日 | 今日=橙徽标；逾期=红徽标；未来=主色或中性 |
| 动作组（详情） | 主操作「记跟进」填充；成交/无法成交等次级；重启在非跟进态高亮 |

## 7. 实现映射（Ant Design）

- 色板尽量映射 AntD token（`colorPrimary: #2563EB` 等），不要两套主色
- 用 `Tag`/`Badge` 表达阶段与状态；状态映射表见上
- 表格密度 `middle`；表单 `Form` + `message`/`Modal` 反馈
- HTML 稿含 Tailwind CDN，**仅供对照视觉**，生产用 AntD，不引入 Tailwind（避免双栈）
