# 凯俊后台 技术方案

> 对应 PRD：`docs/PRD.md` v0.3（已确认）  
> 阶段：方案稿 · 待用户确认后进入开发

## 目标（一句话）

为个人/内网自用的 IT 产品经理工作台，提供**以项目为主线**的状态可见、跟进循环、工时/调研/话术沉淀的可运行 Web 应用（MVP）。

## 选型

| 候选 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| Next.js 全栈 | 一体部署、生态大 | 对 MVP 偏重，心智负担高 | 不选 |
| **Vite + React 18 + TS + Ant Design 5** | 主流、资料多、后台组件齐、Cursor 熟悉 | 需前后端分目录 | **前端采用** |
| Vue3 + Element Plus | 中文生态好 | 与后续扩展无强绑定差异 | 备选（未选，避免摇摆） |
| **Node 20 + Express + better-sqlite3** | 依赖少、同步 API 简单、单文件库、本机/内网足够 | 无迁移生态（MVP 可手写 schema） | **后端采用** |
| Prisma + SQLite | 迁移友好 | 多一层抽象 | MVP 不引 |
| Next/Auth 或 Passport | 功能全 | 过重 | **自实现会话 Cookie** |
| PostgreSQL / MySQL | 生产级 | 部署重 | 不选（PRD：本机/内网） |

**原则对齐**：主流栈、依赖最小、成熟优先、不为以后可能做设计。

### 依赖清单（每项一句理由）

| 依赖 | 理由 |
|---|---|
| express | 成熟 HTTP 框架，路由/中间件足够 |
| better-sqlite3 | 嵌入式 SQL，零外部服务 |
| cookie-session | 极简服务端会话，避免 JWT 复杂度 |
| bcryptjs | 密码哈希（纯 JS，免编译） |
| zod（可选，服务端入参校验） | 防脏数据入库；若嫌重可手写校验 |
| react / react-dom / react-router-dom | SPA 与路由 |
| antd | 表单、表格、日期、反馈组件，省自研 |
| dayjs | 日期计算（下次跟进日 +N 天） |
| vite / typescript / concurrently（dev） | 开发与构建 |

前端构建产物由 Express 托管（生产单端口）；开发时 Vite 代理 `/api`。

## 数据模型

```sql
users (
  id INTEGER PK,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TEXT NOT NULL
)

projects (
  id INTEGER PK,
  name TEXT NOT NULL,
  customer_name TEXT,
  contact_info TEXT,
  customer_note TEXT,
  tags TEXT,                    -- JSON 数组字符串
  stage TEXT NOT NULL,           -- intent | demand | proposal | done
  is_deal TEXT NOT NULL,         -- no | yes
  status TEXT NOT NULL,          -- following | waiting | paused | delayed | lost | won
  expected_amount REAL,
  deal_amount REAL,
  next_follow_up_at TEXT,        -- ISO date, NULL=不约
  opened_at TEXT,
  closed_at TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
)

follow_ups (
  id INTEGER PK,
  project_id INTEGER NOT NULL,
  occurred_at TEXT NOT NULL,
  channel TEXT,                  -- chat | phone | wechat | quote | other
  content TEXT NOT NULL,
  next_follow_up_at TEXT,
  created_at TEXT NOT NULL
)

tasks (
  id INTEGER PK,
  project_id INTEGER,            -- 可空
  title TEXT NOT NULL,
  status TEXT NOT NULL,          -- todo | doing | done
  due_date TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
)

time_entries (
  id INTEGER PK,
  project_id INTEGER,            -- 可空
  work_date TEXT NOT NULL,
  hours REAL NOT NULL,
  note TEXT,
  created_at TEXT NOT NULL
)

research_notes (
  id INTEGER PK,
  project_id INTEGER,
  title TEXT NOT NULL,
  source_url TEXT,
  summary TEXT,
  tags TEXT,                     -- JSON
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
)

scripts (
  id INTEGER PK,
  scenario TEXT NOT NULL,        -- 场景
  stage_hint TEXT,               -- 适用阶段，可空
  body TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
)
```

### 状态机（后端校验）

```text
任意非 lost/won --记跟进/改状态--> following | waiting | paused | delayed
lost|paused|delayed --重新启动--> waiting（或 following）
following|waiting --成交--> won 且 is_deal=yes
任意 --无法成交--> lost 且 is_deal=no
won/lost --改状态--> 仅允许重新启动路径，历史 follow_ups 只增不删
```

`next_follow_up_at`：仅 `following`/`waiting` 时进入「待跟进」查询：
`status IN ('following','waiting') AND next_follow_up_at IS NOT NULL AND next_follow_up_at <= today`

## 接口设计（REST，前缀 `/api`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 登录 |
| POST | `/api/auth/logout` | 登出 |
| GET | `/api/auth/me` | 当前用户 |
| GET/POST | `/api/projects` | 列表（筛选）/ 新建 |
| GET/PATCH | `/api/projects/:id` | 详情 / 更新（阶段、状态、金额、下次跟进） |
| POST | `/api/projects/:id/followups` | 新增跟进（可带 next_follow_up_at） |
| GET | `/api/projects/:id/followups` | 时间线 |
| POST | `/api/projects/:id/actions` | `restart` \| `lose` \| `win` \| `pause` \| `delay` |
| GET | `/api/summary` | 待跟进、阶段分布、金额、工时合计 |
| CRUD | `/api/tasks` `/api/times` `/api/research` `/api/scripts` | 同构简易 CRUD |

写操作一律校验会话；入参白名单，SQL 全部参数化。

## 安全与配置

- 密码：bcrypt 哈希；禁止明文。  
- `SESSION_SECRET` 只放 `.env`，**gitignore**；`.env.example` 仅占位。  
- Cookie：`httpOnly` + 同站；局域网用 `sameSite=lax`。  
- 无硬编码密钥；无调试 log 上生产（dev 可留）。

## 风险与回退

| 风险 | 回退 |
|---|---|
| better-sqlite3 原生模块在 Windows 编译失败 | 改用 `node:sqlite`（Node 22+）或纯 `sql.js`；先试 Node LTS + 预编译包 |
| 状态机过严导致无法修数据 | 提供开发用 script 或详情页「管理员修正」仅改 status |
| AntD 体积 | 可接受（内网）；不引 Pro 全家桶 |
| 单人无迁移工具 | schema 版本表 `meta.schema_version`，升级手写 ALTER |

## 任务拆解建议（交给项目经理）

见 `docs/进度.md` 任务卡；依赖顺序：

1. 项目骨架（Express + Vite + 登录壳）

5. 调研 / 话术
