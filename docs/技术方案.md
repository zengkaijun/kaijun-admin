# 凯俊后台 技术方案

> 对应 PRD：`docs/PRD.md` v0.3（已确认）  
> 状态：**v2.1 修订稿 · 待用户确认**（PHP + Laravel + **Swoole** + MySQL 最新 + Docker + GitHub 多机）

## 目标（一句话）

以 **Docker Compose** 一键起本地开发环境，**Laravel + Swoole（Octane）+ MySQL** 支撑以项目为主线的 MVP，保证克隆仓库即可多机开发，并为后续扩展留口。

## 硬约束（用户拍板）

| 约束 | 落实 |
|---|---|
| 用上 Docker Desktop | `docker-compose.yml` 托管 MySQL / PHP(+Swoole) / 前端开发服务 |
| 后端语言 PHP | **Laravel** |
| **加上 Swoole** | **Laravel Octane + Swoole** 作为应用服务器（不手写裸 Swoole 路由） |
| 数据库 MySQL，版本最新 | 镜像 `mysql:9`；兼容问题回退 **`mysql:lts`（8.4）** |
| 本地开发 | 默认只绑 `127.0.0.1` |
| 上传 GitHub 多机开发 | 完整 README、`.env.example`、无密钥入库、卷与缓存 gitignore |

## 选型

| 层 | 候选 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| 应用框架 | **Laravel 12 + PHP 8.4** | 生态成熟、Eloquent、扩展顺手、Cursor 资料多 | 比 Slim 重 | **采用** |
| 微框架 Slim | 更轻 | 认证/迁移/校验要自建 | 不选 |
| **运行时 / 常驻** | **Laravel Octane + Swoole** | 常驻进程、少反复启动、并发更好；Laravel 官方支持路径 | 与 `artisan serve`/FPM 模型不同；需自定义 PHP 镜像带 `swoole` 扩展；Octane 有状态注意事项 | **采用**（用户要求 Swoole） |
| 裸 Swoole 自研服务 | 可控 | 绕开 Laravel 生态，业务/路由自管 | 不选 |
| 裸 Swoole + Laravel 常规 HTTP | — | Laravel 标准入口是 PHP-FPM/CLI HTTP，**不能**直接当普通扩展用 | 必须经 **Octane** |
| RoadRunner | 同样常驻 | 驱动不是 Swoole | 不选（用户点名 Swoole） |
| API 形态 | **前后端分离 REST** | 可加多端；前端独立 | 多一层代理 | **采用** |
| SPA | **Vite + React + Ant Design 5** | 后台组件齐 | — | **采用** |
| ORM | Eloquent | 迁移与关系 | — | **采用** |
| 认证 | Session Cookie（Octane 下注意驱动） | MVP 简单 | 多端以后再上 Sanctum token | **默认 Session**；预留 Sanctum |
| 本地编排 | **Docker Compose** | 版本锁定、换机一致 | 镜像需拉取 | **采用** |

### 为什么是 Octane + Swoole（不是「随便挂个 Swoole」）

- Laravel 请求生命周期跑在 Swoole **Worker** 里，由 **`laravel/octane`** 托管，属于官方支持的接入方式。  
- 业务仍是普通 Laravel 路由/中间件/Eloquent，**不用**为 Swoole 重写框架层。  
- 开发也统一跑 `php artisan octane:start --server=swoole --host=127.0.0.1 --port=8000`，与生产更接近。  
- 代价：Docker 里 PHP 必须编译/安装 **`ext-swoole`**；Session 用 Octane 兼容配置；避免把单例当跨请求全局状态乱存。

### 依赖原则

- 业务只依赖 Laravel 官方 + **`laravel/octane`**（含 Swoole 驱动）+ 极少数通用包；**每加一个 composer/npm/系统扩展必须写一句理由**。  
- 不为「以后可能」上微服务、K8s；扩展点用模块边界。

## Docker 架构

```text
docker compose
├── db      image: mysql:9（或 mysql:lts）
│           卷: mysql-data:/var/lib/mysql
│           端口: 127.0.0.1:3306:3306
├── app     自定义 Dockerfile：php:8.4-cli
│           扩展: pdo_mysql, mbstring, zip, **swoole**（pecl/docker-php-ext）
│           挂载: ./backend → /var/www/html
│           启动: php artisan octane:start --server=swoole
│                  --host=0.0.0.0 --port=8000
│           端口: 127.0.0.1:8000:8000
└── web     node:22（Vite dev）
            挂载 ./frontend，127.0.0.1:5173:5173
            proxy /api → app:8000
```

**命令（写入 README）**：

```bash
docker compose up -d --build
docker compose exec app composer install   # 首次
docker compose exec app php artisan key:generate
docker compose exec app php artisan migrate
docker compose exec app php artisan db:seed
# 确认 octane 已装并已 start（compose command 可直接带）
docker compose logs app   # 应看到 Octane / Swoole 启动日志
```

换电脑：`git clone` → 复制 `.env.example` 为 `.env` → `docker compose up -d --build` → migrate/seed。

### 仓库与 GitHub

| 进 git | 不进 git |
|---|---|
| `docker-compose.yml`、`Dockerfile`（如有） | `.env` |
| 代码、迁移、种子、README | `vendor/`、`node_modules/` |
| `.env.example`（占位符） | `storage/logs/*`、`data/` |
| 前端源码与锁文件 `package-lock.json` | 本地数据库卷 |

`.env.example` 必含：`APP_KEY=`、`DB_HOST=db`、`DB_DATABASE=`、`DB_USERNAME=`、`DB_PASSWORD=`、`SESSION_*`。  
**密钥零入库**：真实口令只在本机 `.env`。

## 数据模型（与 PRD v0.3 对齐）

沿用原表结构语义，改为 Laravel migrations + Eloquent；日期用 `DATE`/`DATETIME`，金额 `DECIMAL(12,2)`。

- `users` — 管理员  
- `projects` — 主线：`stage`、`is_deal`、`status`、`next_follow_up_at`、金额、客户字段（依附项目）  
- `follow_ups` — 跟进循环（只增不删）  
- `tasks`、`time_entries`、`research_notes`、`scripts`  

**状态机**与 v1 相同（后端用 PHP enum / 验证规则强制）：

```text
following|waiting|paused|delayed ⇄ 各动作
lost|paused|delayed --restart--> waiting
--win--> won + is_deal=yes
--lose--> lost + is_deal=no
待跟进: status IN (following,waiting) AND next_follow_up_at <= CURDATE()
```

## API（`routes/api.php`，前缀 `/api`）

与 v1 表一致：`auth/*`、`projects`、`projects/{id}/followups`、`projects/{id}/actions`、`summary`、`tasks`、`times`、`research`、`scripts`。

- 登录：`POST /api/auth/login` → session（Sanctum 亦可，实现时二选一写明）。  
- 写接口：登录中间件 + FormRequest 校验。  
- CORS：开发仅允许 `http://127.0.0.1:5173` / `localhost:5173`。

## 风险与回退

| 风险 | 回退 |
|---|---|
| `mysql:9` 与 PHP 镜像不兼容 | 改 `mysql:lts`（8.4） |
| **Swoole 扩展在自定义镜像编译失败** | 先用官方 `php:8.4-cli` + `pecl install swoole` 预编译包；失败则临时 **`php artisan serve` 降级跑通业务**，Swoole 作并行任务不挡 T2+ |
| Octane 长驻导致状态残留 | 约定：不用静态属性存请求态；必要时 `octane:reload` |
| Session 在 Octane 下异常 | 换 `SESSION_DRIVER=database` 或 cookie 方案并写进 README |
| Laravel 首次上手偏重 | 任务拆细；由 Cursor 按任务卡生成 |
| Windows 路径/权限 | 全部在 Linux 容器内操作；vendor 在容器内 install |
| GitHub 含密钥 | `.env` gitignore + 评审 |
