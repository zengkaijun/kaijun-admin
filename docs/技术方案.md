# 凯俊后台 技术方案

> 对应 PRD：`docs/PRD.md` v0.4（已确认）  
> 状态：**已确认**（用户拍板）  
> 栈：PHP + Laravel + **Octane/Swoole** + **MySQL 8.4** + Docker + GitHub；**不加 Redis**；**不用 ThinkPHP**

## 目标（一句话）

以 **Docker Compose** 一键起本地开发环境，**Laravel + Octane/Swoole + MySQL 8.4** 支撑「项目 → 跟进 → 工作项 → 首页待办」MVP，保证克隆仓库即可多机开发。

## 硬约束（用户拍板）

| 约束 | 落实 |
|---|---|
| Docker Desktop | `docker-compose.yml`：db / app / web |
| 后端 PHP + Swoole | **Laravel 12 + Octane + Swoole**（不用裸 Swoole、不用 ThinkPHP） |
| 数据库 MySQL **8** | 镜像 **`mysql:8.4`**（回退 `mysql:8.0`） |
| **不用 Redis** | Session 用 database；缓存 file/database；无队列 |
| 本地 127.0.0.1 | 三服务均只绑本机 |
| GitHub 多机 | README、`.env.example`、无密钥入库 |

## 选型

| 层 | 结论 | 理由（一句） |
|---|---|---|
| 框架 | **Laravel 12 + PHP 8.4** | CRUD/迁移/校验现成，Cursor 资料多 |
| 应用服务器 | **Octane + Swoole** | 官方接入路径；失败可临时 `artisan serve` 排障 |
| 数据库 | **`mysql:8.4`** | 用户指定 8 系；8.4 为 LTS |
| 会话 | Session Cookie + `SESSION_DRIVER=database` | 单人 MVP 够用；不引入 Redis |
| 前端 | Vite + React + Ant Design 5 | 后台组件齐 |
| 编排 | Docker Compose | 换机一致 |
| 缓存/队列 | 默认 file / 不建队列 | YAGNI；以后通知再扩展 |

### 明确不用

- **ThinkPHP + Swoole**：与 Laravel 重叠且本仓半成品/任务卡按 Laravel；无额外收益  
- **Redis**：本期无共享 session、无队列、无高并发缓存需求  
- 工时 / 调研 / 话术表：PRD v0.4 非目标  

## Docker 架构

```text

│           卷: mysql-data
```

## 数据模型（对齐 PRD v0.4）

日期 `DATE`/`DATETIME`，金额 `DECIMAL(12,2)`；Laravel migrations + Eloquent。

- `users` — 单管理员  
- `projects` — `name`、`start_date`、`customer_name` **必填**；`stage`、`is_deal`、`status`、`priority`、`sort_order`、金额、`parent_project_id`  
- `follow_ups` — 只增不删；`occurred_at`、`channel`、`content`、`next_follow_up_at`、可选 `stage_after`/`status_after`  
- `work_items` — `title`、`status`、`due_date?`、`project_id?`、`type`（milestone|task）、`priority`、`sort_order`  

**枚举**：

```text
stage:  demand | proposal | development | testing | delivered
is_deal: no | yes
status:  normal | paused | stopped
channel: talk | phone | wechat | quote | other
work:    todo | doing | done
type:    milestone | task
priority: high | normal | low
```

**状态机**：

```text
normal
  --win-->  normal + is_deal=yes + 清空下次跟进日
  --lose--> stopped + is_deal=no
  --pause--> paused
  --stop--> stopped
paused --stop--> stopped
paused|stopped --restart--> normal（历史保留）

未成交跟进（总览）: is_deal=no AND stage∈(demand,proposal) AND status∈(normal,paused)
```

## API（`/api`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/login` `/auth/logout` | Session |
| GET | `/auth/me` | 当前用户 |
| GET/POST | `/projects` | 列表（筛 stage/is_deal/status；可选 page/per_page=10\|20\|50\|100，默认10）/ 新建 |
| GET/PATCH | `/projects/{id}` | 详情 / 编辑 |
| GET/POST | `/projects/{id}/followups` | 时间线 / 记跟进 |
| POST | `/projects/{id}/actions` | `win\|lose\|pause\|delay\|stop\|restart` |
| GET/POST | `/work_items` | 列表（筛 status/type/project_id；可选 page/per_page）/ 新建（`project_id` 可空） |
| GET/PATCH/DELETE | `/work_items/{id}` | 详情 / 改 / 删 |
| GET | `/summary` | 未成交跟进 + 未完成工作项（含 priority/sort_order） |
| POST | `/summary/reorder` | 总览拖拽排序（`list` + `ordered_ids`） |

写接口：登录中间件 + FormRequest；非法枚举 **422**；未登录 **401**。  
CORS/代理：开发仅 `127.0.0.1:5173` → `/api`。

## 风险与回退

| 风险 | 回退 |
|---|---|
| `mysql:8.4` 异常 | 改 `mysql:8.0` |
| Swoole 扩展编译失败 | 报错原文入文档；临时 `artisan serve` 跑通登录 |
| Octane Session 异常 | 确认 `SESSION_DRIVER=database` |
| Octane 长驻状态残留 | 不用静态属性存请求态；必要时 `octane:reload` |
| 仓内 `backend/` 半成品 | T1 续做或按任务卡补齐；**口令不进 git**（compose 默认口令仅本机，生产改 env） |
| GitHub 密钥 | `.env` gitignore + 评审 |
